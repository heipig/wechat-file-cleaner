# 微信收发文件清理器

[English](README.en.md) | **简体中文**

清理微信电脑版攒下来的收发文件：告诉你哪些是**你发出去的**、哪些在硬盘别处**还留着一份**，然后批量删掉，把空间腾出来。

- 绿色免安装，解压双击就能用
- 不用装 Node.js、Python、.NET，什么都不用装
- 微信 4.x（`xwechat_files`）和 3.x（`WeChat Files`）都能用
- 全程离线，不联网、不上传你的任何文件

> 现状：能用，但最初是为一位用户的实际情况写的。开始前请扫一眼[运行要求](#运行要求)。

## 它解决什么问题

微信**收到的**文件，你当时另存过一份，但早忘了存哪了。
微信**发出去的**文件，原件本来就在你电脑上，微信里那份纯属重复。

这两种情况偏偏分不清，而 Windows 自带的搜索慢到没法拿来核对几千个文件。

这个工具几秒钟把这件事做完。

## 下载

1. 打开 [Releases 页面](https://github.com/heipig/wechat-file-cleaner/releases/latest)
2. 下载 `微信收发文件清理器-portable.zip`（约 133 MB）
3. 解压到任意目录 —— 桌面、D 盘、U 盘都行，**路径里有中文或空格也没关系**
4. 双击 `微信收发文件清理器.exe`
5. 弹出 UAC 提示（"你要允许此应用对你的设备进行更改吗？"）时点**「是」**

> 为什么要管理员权限？为了几秒钟建好整盘索引，程序要直接读 NTFS 的主文件表，这在 Windows 上属于管理员级操作。不想提权也能用，见下面的[常见问题](#常见问题)。

## 怎么用：就三步

界面顶部有 `① 选择微信文件夹`、`② 建立备份索引`、`③ 查备份` 三个状态提示，跟着它们走就不会漏步骤。三个都变成已完成状态时，结果才可靠。

### 第 1 步：选择微信文件夹

点「浏览…」，选到微信存放收发文件的**那一层**：

| 你的微信版本 | 要选的文件夹 |
|---|---|
| 4.x（新版） | `C:\Users\<用户名>\Documents\xwechat_files\<wxid>_<后缀>\msg\file` |
| 3.x（旧版） | `C:\Users\<用户名>\Documents\WeChat Files\<wxid>\FileStorage\File` |

**不确定在哪儿？** 打开微信 →「设置」→「文件管理」，那里能看到保存位置，点「打开文件夹」直接跳过去。如果你把存储位置改到过别的盘，就去那个盘里找同名的 `msg\file` 目录。

- 「包含子文件夹」默认勾选，会把下面 `2024-01`、`2024-02`… 所有月份一起扫，**建议保持勾选**。
- 只想清视频，把路径换成 `msg\video`（3.x 是 `FileStorage\Video`）即可。

选好路径，点 **「开始扫描」**。文件列表立刻出现，每行带大小、修改时间、月份和初步的「收发判定」。

### 第 2 步：建立备份索引

这一步是让程序"知道你硬盘上都有什么文件"，之后才能判断某个文件在别处有没有副本。

- **默认方式：整盘（NTFS 主文件表）** —— 勾选要查的盘（可多选），点「建立全盘索引」。几十万个文件通常 2～6 秒。
- 只有 NTFS 格式的盘能被这样索引；FAT32 / exFAT 的盘会被自动跳过，不影响使用。

### 第 3 步：查备份

点 **「查备份」**。程序先按"文件名 + 大小"筛出候选，再用**内容哈希**逐个核对，确认硬盘别处真的有一份一模一样的文件。

跑完后，「备份」列会标出每个文件有没有找到备份，「备份位置」列直接告诉你另一份在哪儿。

## 看结果：哪些能放心删

| 列 | 含义 |
|---|---|
| 文件名 / 大小 / 修改时间 / 月份 | 文件本身的信息；「月份」指它在微信里的那个 `2024-01` 文件夹 |
| 类型 | 文档 / 图片 / 视频 / 音频 / 压缩包 / 可执行 / 其他 |
| 收发判定 | **发送件**（修改时间明显早于所在月份，多半是你发出去的）、**接收件**，或**不确定** |
| 备份 | **有备份**（别处确认有一份一样的）、**无备份**、**未查** |
| 备份位置 | 另一份文件在哪儿，点这一列会弹出完整路径 |

**最值得删的，是那些"判定为接收件、但备份显示有备份"的文件** —— 说明这文件你当初另存过，微信里这份已经是多余的了。

筛选和排序：

- 顶部「全部文件 / 仅有备份 / 仅发送件 / 仅接收件 / 未查备份」一键切换
- 「按文件名过滤」边打字边筛，不用等
- 还能按类型、月份、大小（大于 N MB）过滤
- 点列标题可以排序

选中文件：按住 **Shift** 选一整片，按住 **Ctrl** 点选不连续的几个，和资源管理器一样。另外还有 `全选`、`反选`、`选中有备份`、`选中无备份` 四个快捷按钮。左下角会实时显示已选了几项、总共多大。

## 删除

选好文件后，在右下角选删除方式，再点 **「删除选中」**：

- **移到回收站**（默认，安全）—— 删错了还能捞回来
- **永久删除** —— 不进回收站，空间立刻释放，**不可恢复**

点下去会弹一个确认框（画在程序窗口里的那种，不是系统弹窗），确认后开始删。微信给文件加的只读属性程序会自动处理，不用你操心。

> 第一次用建议先选「移到回收站」，删完确认没误删，再考虑永久删除。

## 常见问题

**提示「未以管理员身份运行」怎么办？**
点横幅上的「以管理员身份重启」。也可以关掉程序，右键 exe →「以管理员身份运行」。

**没有管理员权限能用吗？**
能。把「备份索引」下拉改成「只索引指定文件夹（不需管理员）」，再点「选择文件夹…」，把可能存放备份的几个目录加进去（比如 `D:\文档`、`D:\下载`）。慢一些，但不用提权。

**点了「建立全盘索引」失败，或提示盘读取失败？**
多半是没提权。看顶部那条黄色横幅，或点「自检」，它会告诉你卡在哪一步。

**为什么我的某个盘被跳过了？**
那个盘不是 NTFS 格式（常见于 exFAT 的移动硬盘、FAT32 的 U 盘）。直接读主文件表是 NTFS 独有的能力，这种盘只能改用「只索引指定文件夹」模式。

**某个文件被判定成「发送件」，但我记得是别人发我的？**
这条判定基于文件修改时间，是经验推断，不是微信官方数据。所以界面上它和「备份」是**两列互相独立的信号**，请一起看，别只看一列就下手删。

**杀毒软件报毒 / Windows 拦截了？**
程序没有代码签名（个人项目，签名证书要花钱），部分杀软对未签名程序会误报。源码完全公开，可以自己审查、自己构建。确认没问题后加白名单即可。

**日志按钮是干什么的？**
换电脑排查问题时，点「查看日志」可以直接看程序日志，点「打开日志文件夹」定位到文件。日志同时写在 exe 旁边的 `logs\app.log`，跟着程序走，拷到别的机器也带着。

**界面太亮或太暗？**
就绪栏最右边的「浅色 / 深色」按钮可以切换，第一次运行跟随系统主题，之后记住你的选择。

**会不会偷偷上传我的文件？**
不会。程序全程离线，界面本身禁止一切网络请求，所有判断都在你本机完成。

## 已知不足

- **收发判定是经验推断**：当月收到、当月又发出去的文件会被算成接收件。这正是要有「备份」这一列的原因。
- **整盘索引每次启动都要重建**，约 2～6 秒。
- **只支持 64 位 Windows。**
- **超过 64 MB 的大文件用抽样比对**（精确大小 + 多段采样），不是全文哈希，理论上存在极低概率的漏判。
